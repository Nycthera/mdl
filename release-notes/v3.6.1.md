# MDL v3.6.1

## Highlights

- Replaced the CBZ SHA-256 value with a fast XXH3-128 local fingerprint.
- Hashes CBZ files in bounded chunks to keep memory use low.
- Stores the fingerprint in the `manga_data.cbz_hash` database column.
- Adds optional developer logging for fingerprint calculation time.
- Adds the `xxhash` runtime dependency.

## Compatibility

- Requires Python 3.13 or newer.
- Existing databases are migrated to include `cbz_hash`.
- XXH3 is intended for local change detection and is not a cryptographic checksum.
