# MDL v3.5.1

This release fixes archive data loss and incorrect download tracking, and ships the single-file distribution with a committed dependency lockfile.

## Fixes

- Preserve previously archived chapters when updating a CBZ. Build the replacement atomically, exclude pending downloads and other archives, and retain source folders for recovery.
- Count successful pages rather than queued pages. Incomplete or interrupted batches are not automatically packaged, and MangaDex progress stops at the first incomplete chapter.
- Place Webtoons episodes under their series folder and download the image URLs extracted from the requested WeebCentral page.
- Choose one mirror per page filename to avoid concurrent overwrites.
- Check direct-image hosts for updates even when cached chapter numbers match; downloading older chapters no longer moves recorded progress backward.
- Reject lookalike source hostnames, sanitize unsafe folder names, and exclude query strings from downloaded filenames.
- Respect retry settings across download paths, validate numeric CLI arguments, support `--no-cbz`, and use the correct MangaDex data-saver endpoint.
- Clean up download tasks on cancellation. Validate configuration and save it atomically without filesystem writes during module import.
- Fix shared HTTP session construction and preserve separate module namespaces in the legacy single-file build command.
- Retain the existing main-branch installer protection for unrelated broken command symlinks.

## Distribution and documentation

- Ship `mdl.py`, `pyproject.toml`, `uv.lock`, `LICENSE`, `INSTALL.txt`, `RELEASE_NOTES.md`, and `SHA256SUMS`. Python 3.13+ and separately installed dependencies are required; these source assets replace older platform binaries.
- Replace the nonexistent setup-uv action reference with the verified v10.1.0 commit in both CI workflows.
- Track `uv.lock` so clean checkouts, CI, and installations can use the same locked dependencies.
- Refresh the AI project guide and document review findings and source-specific limitations.

## Upgrade notes and limitations

- CBZ creation now retains downloaded chapter folders, increasing disk usage while preserving resumable files.
- Database auto-update currently probes generic direct-image hosts. Existing rows do not store source URLs or IDs; rerun the original URL for MangaDex and browser sources.
- Live websites were not exercised in the local review. Webtoons pagination completeness, bounded-memory streaming, and adaptive host concurrency remain unverified or incomplete.
- `--update` synchronizes dependencies; rebuild/reinstall the standalone command to update application code.

- Ruff lint and formatting checks pass.
- Release version/tag consistency, standalone execution outside the checkout, and asset checksums are verified by the release build.
