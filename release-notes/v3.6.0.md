# MDL v3.6.0

## Highlights

- Added download verification and repair workflows.
- Added optional image optimization for CBZ output.
- Improved database maintenance, scraper behavior, HTTP handling, and CLI validation.
- Expanded regression coverage for unsafe paths, invalid configuration, cancellation, and release validation.

## Compatibility

- Requires Python 3.13 or newer.
- Runtime dependencies remain managed by `uv.lock`.
